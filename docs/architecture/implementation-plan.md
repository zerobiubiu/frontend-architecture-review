# 后端技术栈与 API 边界现状

- 类型：架构说明、开发指导。
- 状态：后端现状参考，运行入口见[后端说明](../../backend/README.md)。
- 范围：单账户 Binance Stocks 官方支持证券，含普通股、ETF；交易员／管理员权限独立。买卖执行均需逐次核实相应资金或证券库存来源。

## 技术栈与职责

|能力|实施边界|
|---|---|
|运行时与 API|Bun、TypeScript、Hono；HTTP API与Worker独立运行|
|数据库|PostgreSQL 18.6、Drizzle ORM／Kit；首次连接核对日志／哈希并加锁自动迁移，失败阻断；JSONB使用原生对象编码|
|交易所接入|官方 Stocks 1.0.6／Wallet 22.2.7；Common 2.5.2 和 Axios 固定版本，统一凭据、安全传输和业务适配|
|公开契约|后端Hono RPC声明与Zod schema导出，供外部调用方独立集成|
|金额与数量|decimal.js；金额 NUMERIC(38,18)、数量 NUMERIC(30,10)，公开数量字符串；未知费用／资产不填零|
|安全|Session、HttpOnly Cookie、CSRF／Origin、角色／owner、限流、凭据加密与审计|
|后台执行|独立 Worker、数据库事务／行锁、持久化任务、恢复先核对，事件连接在停机时关闭|
|实时更新|业务SSE按9类资源发布变化；报价由后端鉴权SSE中转，先发REST快照，后转发官方SDK行情，缺少推送时后端静默补读；私有订单流独立，客户端不连第三方API|
|交付范围|后端代码与业务资料；不提供Docker、NGINX、容器CI或主机部署配置|

不新增 K 线、图表、技术指标、加密货币、衍生品、代币化交易、回测、Redis、消息队列或微服务。证券不按类别筛选，由官方 `exchangeInfo()` 唯一决定准入。

`GET /api/v1/market/quote-stream?accountId&symbol`沿用会话／来源／所有权和SSE配额，先通过统一SDK与限流客户端读取REST快照，再转发官方行情；WS先到时晚REST不得覆盖，缺少WS有效更新时后端每5秒补读且仅一个在途读取。服务端接收、来源T与事件E分别表示，不伪造实时状态；会话失效、账户凭据变化、连接关闭及API停机释放订阅。业务SSE仍按9资源发布变更，订单预检和执行继续独立校验；官方匿名端点也只由后端访问。实施见[0033](../changes/0033-backend-quote-relay.md)。

当前数量范围预检按用户确认的策略分别校验官方实际返回的minQty/maxQty；缺失值保持null，不自行补值或单因缺失阻断。已知越界、上下限矛盾仍拒绝，诊断回显本次股数、实际边界及缺失项；不套用Spot零值语义，其他交易安全校验独立保留。现行策略见[0034](../changes/0034-optional-quantity-bounds.md)，[0032](../changes/0032-quantity-range-diagnostics.md)保留此前仅改善诊断的历史事实。

批量任务的有效数量范围由官方规则与当前取价配置决定。固定价使用有效规则与明确价格；BID_1／ASK_1还须新鲜报价，规则过期不能推定范围。后端按总目标扣除已成交及未结委托剩余量裁剪实际批次，再检查金额、步长和GTC尾量；保存草稿不修改已有订单。执行规则见[0043](../changes/0043-batch-execution-redesign.md)。

## 后端项目与职责分区

当前仅后端为`3.0.0`，以`backend/package.json`为版本事实源。市价单及金额目标见[0058](../changes/0058-market-orders.md)：三类严格输入、可空意图字段、真实成交本金、金额批量及迁移0015，旧任务保持LIMIT。公开响应模型不兼容旧消费者，实际客户端、API、Worker仍须配套升级且禁止新旧执行进程混跑。此前盘口限价策略和账户原回执分别见[0057](../changes/0057-quote-price-rounding.md)、[0055](../changes/0055-account-operation-receipts.md)；限价规则、UUID回执、原窗口和未知只核对继续保留。本次未部署或执行真实买卖、撤单。

后端采用[轻量DDD模块化单体](domain-driven-design.md)：`server` 组织HTTP，`services` 组织应用用例与具体SQL事务，`domain` 组织不依赖HTTP／DB／SDK／公开DTO的纯金融规则，`api` 是官方SDK防腐层。保留真实事务、账户／任务／订单锁与应用端口，不建泛型仓储、CQRS、事件溯源或微服务。配置、数据库、安全、校验、内部类型、工具、Worker及工程配套仍分区，不保留旧入口shim。

## 唯一正式交易接入

- 不再有运行时本地模拟、虚拟资金、模拟行情或交易测试环境，也不读取 `TRADING_ENV`。程序开发模式不是资金安全隔离模式。
- API／Worker统一封装Stocks与Wallet；HTTP路由和调度器不重复实现签名或传输，官方服务端SDK与交易所凭据不提供给客户端。
- 节点只从正式官方白名单选择；`auto` 通过 SDK匿名只读时间请求探测，再将选定来源传给 API／Worker。结果未知时不因换节点重发写请求，不以节点切换绕过限流。
- 官方429／418冷却由 `exchange_rate_limits` 持久化并在 API／Worker、账户和节点之间共享；SDK传输层保存可取得的 `Retry-After`，缺少时采用有界指数退避。冷却期间停止新的官方请求，已在途请求仍可能返回；真实限流响应不作为确定未发送证据。
- SDK写请求不采用通用自动重试；首次提交前持久化原客户订单标识，超时、网络故障或不明结果进入原订单核对。
- 本地门禁在单次下单HTTP发送前明确阻断时，保留专用未发送证据并锁内安全终结；提交后的观察冷却不属于该证据，不能释放占用。
- SDK状态、真实逐笔执行和累计费用映射为业务证据；未提供逐笔费用时不能假分摊或填零，名义成交金额不是已核实的现金结算。
- `tokenize=false` 保持非代币化证券交易；不自动签署声明、换币、划转或调用无关产品的交易接口。
- 官方错误页221条定义／220唯一码由统一策略覆盖，按READ／SUBMIT／CANCEL／STREAM区分。HTTP400加显式白名单才是拒单证据；2xx错误包络、重复ID、系统故障、查无单、撤单中都不能释放未知占用。失效私有流在完整退避期保持降级；[逐码审计](../reference/stocks-error-handling.md)列出原缺口、当前处置与限制。

## 官方资金、动态证券与执行边界

买入从官方 Funding USDC 读取当次可用余额。Spot 钱包只读展示，不与 Funding 拼成可用预算。本地 PLANNED 未提交意图加费用预留占用预算；ACCEPTED 等订单已由交易所冻结，不重复扣减。HTTP 取证在锁外，事务内以凭据和 `tradingRevision` 检查并发变化及15秒资金证据时效。

证券目录使用官方 `exchangeInfo()`，按账户／凭据摘要存 PG，TTL 300秒、提前60秒刷新、30秒刷新租约；失败不延长期限，查询过期源拒绝。目录分页不限制证券总数，自由输入仍须官方验证。任务保存与每笔执行重新检查方向、上市／下架、数量步长、范围、金额、小数能力、时段和挂单上限。

费用政策只是资金预留估算；订单实际累计费用来自官方 USD 字段，未知值继续待核对。成交量、任务进度和本地名义成本使用 Decimal 精确累计，executionId 去重。外部市价订单原始 notional 币种未核实时保留原值与“币种待核”，不猜现金流。

市价BUY用本金目标，不生成请求股数；市价SELL用股数，当次bid仅估算名义金额。两者不发送价格／交易时段且只允许DAY。`filledNotional`从真实逐笔成交累计，MARKET BUY同时核对官方`filledTotal`；金额未对齐继续等待，超出请求本金拒绝入账。金额任务用总本金减已成交本金和活动未成交本金限制批次，费用另预留，未用余款不冒充进度。本站18位金额表示与盘口价格限制分离，不构成真实现金结算证明。

订单 `fee` 表示已入账累计费用，`feeFinalized` 单独表示终态费用已经官方明确返回。部分成交曾返回费用不能代替最终确认；终态缺费仍由周期、重启和手动核对继续查询，迟到费用仅入账差额。历史记录默认未最终确认，不改历史金额。

SELL逐次核实官方Funding可用量及证券身份映射；来源缺失或冲突时禁止卖出。本地名义持仓不作为可卖量。成交后库存比较是保守门禁，不证明订单与钱包原子同步，限制见[0042](../changes/0042-sell-production-integration.md)。能力可用不代表账户或当次订单通过校验；管理员只有监管与安全控制，不能产生交易意图。

## 持久化与账户数据

数据库仍只配置一个 `DATABASE_URL`。用户确认新建 `equity_production`；首次初始化仅创建缺失的网站账号，不创建币安交易账户或业务任务，现有业务数据以实际数据库为准；旧 `equity_simulation` 保留原有用户和业务数据，不迁移为正式记录。

固定的正式库标识用于误连接保护，不是多环境切换配置。迁移前拒绝历史非正式标识，新追加生产迁移拒绝删除非空演示表；历史 SQL 和快照不重写。主密钥保留，凭据 AAD 使用固定正式用途绑定；旧会话不搬到新库。

首次服务连接读取打包journal与已执行哈希，持有同一保留连接的数据库锁核对、自动迁移并复核；多进程不能同时跑DDL。较新DB、历史不匹配、缺资源或失败均阻断；`dist/migrations`必须随构建部署。首次建库／账号初始化仍显式setup，不在连接时静默创建网站账号；具体命令及权限见运行说明。

凭据替换在账户行锁内检查所有未完成订单、未释放占用、有成交但最终费用未确认的订单以及未终结任务，存在任一项即拒绝覆盖。提交相同凭据保留原密文与连接；实际更换后关闭交易并要求重新验证。当前未提供官方账户身份验证，不能将更换成功解释为已证明两个 Key 属于同一官方账户。

数据库测试通过同一连接账号创建本次专用临时库，向子进程覆盖同一个 `DATABASE_URL`，执行后只清理本次资源，不在正式业务表跑回归。

## 权限、契约与调用方

- 内部路由统一 `/api/v1`，保留错误码、请求 ID、分页、UTC 时间、十进制字符串及脱敏。
- API 权限是权威边界：管理员不能提交买卖；交易员不能跨账户 owner，写请求需可信来源和有效 CSRF。
- 后端 `contracts:export` 从 `src/server/app` 与 `src/validation/contracts` 导出 `contracts/client.d.ts`、`contracts/validation.ts`；客户端声明不泄漏数据库、Bun或 SDK内部类型。
- 外部客户端按公开导出契约调用，Funding／Spot原始钱包、同步时间与失败，以及本地名义账本保持独立；不能用本地资产回退为官方来源。
- 身份与会话由服务端检查；登录、退出、改密及凭据变化后的旧请求结果不能作为新身份或新凭据的证据。
- 受保护动作由`services/operations`协调持久原ID、具体事务和对象互斥。数据库动作与回执同事务，撤单仍依原客户单号及结算终态；GET404、旧快照、客户端记录删除或经过时间不解锁，原ID恢复不重发原动作。

### 客户端接入资料归属

客户端实现以[接入资料](../integration/README.md)为入口，按接口、输入、状态动作、查询、HTTP／SSE、写入恢复和验收规则接入；已知实现差异及未验证边界按对应专题处理。

本篇保留API／Worker、SDK、领域与事务分层等服务端架构职责，不再复制消费者规格或维护另一套DTO。现状资料随当前实现维护；历史测试与部署结果仍只证明各原轮，不能作为新调用方验收。

## 任务时间与订单不变量

- 计划时间不是实际开始；只有预检成功、持锁激活后才记录实际开始、原截止与调度基准。
- 未编辑计划时间保留JSONB原文及原时间列，UTC完整秒／有效小数精确比较不经Date；创建／真实修改最多6位有效小数，历史等价值不截断。顶层Date DTO与配置原文精度边界分开，已开始任务真实改时及原窗口限制保持。
- 启动／继续和每批买入都需当次官方资金预检；保存草稿不查资金，但必须取得有效官方证券规则及报价。
- SERIAL等待前单核对闭环；INTERVAL按受理确认时间计时，允许多笔挂单。聚合已成交和全部未结委托剩余量防止超目标，提交数量不能作为任务完成依据；未知提交／取消、费用或库存未核实仍阻断。
- 暂停、停止、到期或重启不延长既定窗口。KEEP不自动撤单；AFTER_TIMEOUT按每单时钟继续处理，AT_TASK_END在停止／到期处理。确认终态前不释放占用；DAY／GTC独立决定交易所有效期。
- Worker恢复先核对原订单，不重发未知写请求、不补发错过周期；独立25毫秒连续任务调度与完整核对周期并行。停止进程与停止订单不同，停机不能保证准时执行自动撤单。
- 本地提交准备租约与官方订单等待时间分开：未发送意图过期可本地终结；一旦记录 submitStartedAt，未知结果只能核对。明确官方拒单正常终结，不能被异常捕获统一误判 UNKNOWN。
- API 登录有来源／账号／全局限流和密码验证并发上限；代理 IP 显式配置，SSE 连接占用原子计数。限流／SSE配额是进程内保护，多 API 实例部署需评估集中限流；交易互斥、目录租约与财务事实仍由 PG 管理。

## 安全验证与未授权操作

文档、类型或纯规则示例结果不等同于部署、数据库或实盘验收。历史证据仅保留原轮后端与业务功能范围，完整原文在Git历史；隔离夹具不构成运行时模拟环境。

无真实目标账户、正式资产来源或明确下单授权时，不声称真实资金验收通过；开工不等于下单、撤单或风险声明代签授权。HTTPS、部署、备份及外部告警由用户自行安排；历史验证结果不自动沿用为本次证据。
